## Винтовая поверхность 3D
## **Язык**: Python

### **1) Используемые библиотеки:**
- `math` – тригонометрические функции и расчёты.
- `tkinter` – графический интерфейс, создание холста и обработка событий.
  
---

### **2) Математическая модель**

- **Параметры камеры:**
  - Камера расположена в точке вдоль оси Z, расстояние до сцены – `CAMERA_DISTANCE = 600`.
  - Угол поворота:
    - `angle_x` – вращение вверх/вниз (вокруг X).
    - `angle_y` – вращение влево/вправо (вокруг Y).

- **Поворот точки в 3D:**
  - Сначала точка вращается вокруг оси Y:
    ```
    x' = x·cos(ay) - z·sin(ay)
    z' = x·sin(ay) + z·cos(ay)
    ```
  - Затем вращается вокруг оси X:
    ```
    y'' = y·cos(ax) - z'·sin(ax)
    z'' = y·sin(ax) + z'·cos(ax)
    ```

---

### **3) Винтовая поверхность (спиральная трубка)**

- **Задана параметрически**:
  ```
  r = 50 + 10·sin(3·v)
  x(u, v) = r·cos(u)
  y(u, v) = r·sin(u)
  z(u, v) = 30·v
  ```
- **Параметры:**
  - `u ∈ [0, 2π]` – полный оборот по окружности.
  - `v ∈ [0, 2π]` – "высота" вдоль винтовой поверхности.

---

### **4) Проекция из 3D в 2D**

- **Перспективная проекция**:
  ```
  x_proj = x * d / (d + z) + CENTER_X
  y_proj = -y * d / (d + z) + CENTER_Y
  ```
  где `d = CAMERA_DISTANCE`

- Учитывается направление взгляда "вдоль Z", объект становится меньше с удалением.

---

### **5) Визуализация осей координат**

- Отображаются вручную три оси:
  - X – красная
  - Y – зелёная
  - Z – синяя
- Построение через прямое соединение начала координат с концами осей после вращения и проекции.

---

### **6) Закраска полигонов (сканлайн-алгоритм)**

- **Для каждой грани (4 точки)**:
  1. Вычисляются границы по Y.
  2. Для каждой строки `y` находятся пересечения с рёбрами.
  3. Пересечения сортируются, отрезки между ними закрашиваются:
     ```
     t = (y - y1) / (y2 - y1)
     x_int = x1 + t * (x2 - x1)
     ```

- **Закраска реализована вручную**:
  Используется метод `canvas.create_line(x, y, x+1, y)` как псевдопиксель.

---

### **7) Вращение объекта мышью**

- **Реализовано через drag-события**:
  - `dx` – поворот вокруг оси Y
  - `dy` – поворот вокруг оси X
- Углы обновляются, холст перерисовывается при каждом движении мыши.
