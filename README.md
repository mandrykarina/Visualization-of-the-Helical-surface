## Винтовая поверхность 3D

### Параметрическая поверхность:

Винтовая поверхность задается параметрически через функцию  
**F(u, v) = (x(u,v), y(u,v), z(u,v))**, где:

- **u** — угол вокруг центральной оси (в диапазоне от **0** до **2pi**),
- **v** — смещение от центральной линии (в диапазоне от **-0.5** до **0.5**).

Конкретное уравнение для винтовой поверхности:

- **x(u, v) = (50 + 10 * sin(3v)) * cos(u)**
- **y(u, v) = (50 + 10 * sin(3v)) * sin(u)**
- **z(u, v) = 30 * v**

### Вращение:

Вращение фигуры осуществляется вручную с использованием матриц для вращения вокруг осей X и Y.

#### Вращение вокруг оси Y (плоскость XZ):
![image](https://github.com/user-attachments/assets/d80cb923-bf9e-41ae-80cc-9001f49c5f3e)

Применяется к координатам:

- **x' = x * cos(a) + z * sin(a)**
- **z' = -x * sin(a) + z * cos(a)**

#### Вращение вокруг оси X (плоскость XY):

![image](https://github.com/user-attachments/assets/4d4c20ba-378e-41ae-86fa-168c24d0e287)

Применяется к координатам:

- **x' = x**
- **y' = y * cos(p) - z * sin(p)**
- **z' = y * sin(p) + z * cos(p)**

### 4. **Алгоритм Брезенхэма для рисования линий**:
Для рисования отрезков между двумя точками на экране используется алгоритм Брезенхэма. Он аппроксимирует прямую линию между двумя точками, корректируя ошибку при каждом шаге и эффективно рисует линии с пиксельной точностью.

Процесс:
1. Вычисляются приращения \( dx \) и \( dy \) для координат.
2. Определяются шаги по осям X и Y.
3. Рассчитывается начальная ошибка.
4. Затем по шагам исправляется ошибка для точности отображения прямой линии.

### 5. **Закраска полигона вручную (сканлайн-алгоритм)**:
Закраска полигонов на основе пересечений с горизонтальными линиями экрана:
1. Для каждого полигона вычисляются границы по координате \( y \) (минимальное и максимальное значение \( y \)).
2. Для каждой горизонтальной линии внутри этих границ вычисляются точки пересечения с ребрами полигона.
3. Пересеченные точки сортируются по возрастанию \( x \), и между ними происходит закраска пикселей.

### 6. **Обработчик мыши для вращения**:
Пользователь может вращать фигуру с помощью мыши:
- Когда пользователь перемещает мышь с зажатой кнопкой, происходит изменение углов \( \theta \) (для вращения вокруг оси Y) и \( \phi \) (для вращения вокруг оси X).
- Вращение обновляет состояние координат точек и перерасчет проекций.

### 7. **Реализация основных функций**:
- **`rotate_point(x, y, z, ax, ay)`**: Функция для вращения точки в 3D-пространстве по заданным углам \( ax \) и \( ay \).
- **`bresenham_line(canvas, x0, y0, x1, y1, color, tag)`**: Функция для рисования линии с использованием алгоритма Брезенхэма.
- **`project_point(x, y, z)`**: Функция для проекции 3D-точки в 2D с использованием перспективы.
- **`fill_polygon_scanline(canvas, points, color)`**: Функция для закрашивания полигона с использованием сканлайн-алгоритма.
- **`draw_axes(canvas, ax, ay)`**: Функция для рисования осей X, Y и Z вручную.
- **`draw_surface(canvas, ax, ay)`**: Функция для построения поверхности (винтовой поверхности) и ее закрашивания.
- **`redraw(canvas)`**: Функция для перерисовки всего окна с учетом новых углов вращения.

### 8. **Обработка событий**:
- **`on_mouse_drag(event)`**: Обработчик для перемещения мыши, который изменяет углы поворота и перерисовывает сцену.
- **`on_mouse_down(event)`**: Устанавливает начальную позицию мыши для отслеживания движения.
